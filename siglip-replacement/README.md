# SigLIP 2-only anchor nomination

Independent full adaptation-pool nomination and candidate ownership. Compare CLIP-only, CLIP pool + SigLIP rerank, and SigLIP-only at per-class minimum realized seed and extra budgets. Also compare both independent natural-budget pipelines (including scarcity differences). Same available fit and validation rows, same prompts as the prior bank, shared CLIP log-softmax scale for ranking, same cosine gap (0.06), original DINO retrieval and same 50-epoch head. No artificial anchor removal in CIFAR-100, no test scoring, no CLIP student replacement. EuroSAT full train/val; CIFAR-100 same 4,096/1,024 pilot as earlier work. Scores are cached; this does not benchmark backbone latency. Prior experiments are unchanged.

Run `run.py eurosat --smoke`, then `run.py eurosat` and `run.py cifar100` in the robotics research-lab venv, with `/tmp/nola-offline-gpu.lock`. Verified completion is `{dataset}/verified.json`; logs at `{dataset}.log`. Fit labels only enter post-training audits.

Verified: EuroSAT matched CLIP-only 68.02%, CLIP-pool rerank 68.57%, SigLIP 2-only 58.13% (−9.89 pp, 95% CI −11.17 to −8.61). At native budgets: CLIP 68.02% (2,452 anchors) vs SigLIP 60.98% (2,700). On Herbaceous, top-1 correct pool 0 vs 144; matched correct anchors 38 vs 2 of 71; native teacher recall 98 vs 345 of 600. CIFAR pilot: CLIP-only 65.04% vs SigLIP 63.87% (−1.17 pp, 95% CI −3.42 to +1.07), despite correct selections rising from 687 to 718 of 800. No pilot class needed expansion, so the rerank arm is identical to CLIP-only. Intervals are 10,000 within-class paired validation image bootstrap draws; these do not cover seed or dataset variation.

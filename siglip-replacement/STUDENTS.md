# Full backbone replacement through the visual-prompt stage

Eight student arms: EuroSAT and CIFAR-100 coarse, crossed with CLIP-only vs SigLIP 2-only (also the corresponding student backbone), and original DINO vs DINOv3 ConvNeXt-Tiny for expansion retrieval. Refit each verified original-DINO head from its exact anchor IDs and pseudo-labels; require exact parity on all archived validation predictions; then use that teacher's hard labels as student training targets. No true fit labels enter student learning.

Stage 1 desktop pilot: 320 ID-hash-selected fit rows per dataset and 20 validation rows per class, common ordered row sets across arms. Two epochs, 16 visual tokens, common 100× cosine logits, identical augmentation seed and geometry, native validation preprocessing, train prompts + visual LayerNorm + class weights. Common AdamW LR 0.004, label smoothing 0.1, batch 32 accumulated from microbatches of four. This is a matched NoLA-style adaptation, not the release recipe; the SigLIP 2 port prepends prompt tokens after patch position encoding and uses native attention pooling. End-to-end model changes confound nomination with the student architecture; within-VLM retrieval contrasts hold student architecture fixed. No test scoring.

Verified real smoke: all four original teacher predictions reproduced, zero-token path matched each native visual forward, full/tail updates and checkpoint prediction parity passed on both backbones, peak 899 MiB for SigLIP.

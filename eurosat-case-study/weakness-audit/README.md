# NoLA weakness audit

Source: the instrumented EuroSAT CPU replay, one 160-image adaptation pool and a 240-image validation subset. No models retrained. `per-class.csv` distinguishes available true examples (audit only), CLIP top-1 predictions, selected anchors, and correct selected pseudo-labels. `dino-regions.csv` groups adaptation rows by connected components of reciprocal cosine 5-NN links restricted to the same predicted class. At least four rows counts as supported; an anchor counts only if its assigned class matches the region. This is a descriptive graph proxy, not evidence of semantic subtypes. Freeze the graph before comparing selectors, and use 5/10-NN as a sensitivity check in subsequent work.

Observed: Herbaceous Vegetation Land had 24 true adaptation examples, zero top-1 predictions, one incorrect fallback, and 0/16 correct at all three stages on validation. Pasture had 6 examples and no correct anchors; Permanent Crop Land actually had four anchors but all four assigned labels were incorrect. Two of nine supported predicted-class DINO regions lacked assigned anchors; only 3/7 and 1/4 of their rows had correct CDE labels, so coverage by itself could reinforce errors. Final prompted CLIP lost 34 DINO-correct validation predictions and fixed 24 DINO errors, net −10. These are not estimates of prevalence across datasets.

Next experiments, held to a common validation split and matched seeds: (1) freeze anchors and DINO targets and test multi-prototype versus original CDE; (2) freeze original CDE and per-class anchor budget, compare confidence top-k versus confidence-constrained DINO coverage; (3) inspect per-class confusion, supported group coverage and correctness before attempting the combined method. A separate controlled scarcity experiment can subsample known classes or annotated modes in the training pool, but labels used to build that diagnostic are not training inputs; do not present it as a naturally unlabeled protocol. Keep augmentation and training duration fixed initially; if DINO remains healthy and prompted CLIP fails, compare weak versus strong views at equal training budget. Replicate on Oxford Pets after EuroSAT. Keep test data separate from development.

Cloud: start with one interactive private Kaggle GPU notebook, confirm real throughput and output persistence before expanding. A low-cost feature audit does not need a GPU or external upload. No remote run was started for this audit.
